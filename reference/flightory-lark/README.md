# Flightory LARK Reference Material

This directory contains original Flightory LARK reference material used during the development of Project Meadowlark.

These files are preserved as source reference material and are not considered Project Meadowlark designs.

Contents may include:

- Original manuals
- CAD models
- STEP files
- STL files
- Drawings
- Specifications
- Photographs

Project Meadowlark documentation and design decisions are maintained separately under the `/docs` director.y
