# Flightory LARK Reference

## Purpose

This directory contains information about the third-party Flightory LARK airframe used as the reference platform for Meadowlark Platform 1 (MP-1).

It exists to document the relationship between Project Meadowlark and the Flightory LARK without redistributing proprietary material.

It does **not** contain:

- Airframe build instructions
- Proprietary CAD
- STL, STEP, or manufacturing files
- Vendor manuals
- Copyrighted documentation

---

## Relationship to Project Meadowlark

The Flightory LARK serves as the reference airframe for the current MP-1 development platform.

Project Meadowlark documents:

- System architecture
- Hardware integration
- Flight-controller configuration
- Assembly of project-owned components
- Verification procedures
- Engineering decisions

The underlying airframe remains the work of its original designer.

See the following documents for MP-1 engineering information:

- [MP-1 Overview](../../docs/platforms/mp-1/README.md)
- [System Design](../../docs/platforms/mp-1/design.md)
- [Component Selection](../../docs/platforms/mp-1/components.md)
- [Build Procedure](../../docs/platforms/mp-1/build.md)
- [Testing](../../docs/platforms/mp-1/testing.md)
- [Engineering Decisions](../../docs/platforms/mp-1/decisions.md)

## Obtaining the Airframe

The Flightory LARK airframe, documentation, and associated files should be obtained directly from Flightory through its official distribution channels.

Always verify the current licensing terms before downloading, sharing, modifying, or redistributing any third-party material.

## Repository Policy

Only include material in this directory that is permitted for redistribution.

Appropriate content includes:

- Public reference links
- Licensing notes
- Compatibility observations
- Project-specific integration notes

Do not commit proprietary third-party files to this repository unless redistribution is explicitly authorized.

---

## Revision Policy

Update this document when:

- The reference airframe changes.
- Flightory licensing requirements change.
- The relationship between Project Meadowlark and the reference airframe changes.

Routine engineering updates belong in the MP-1 documentation rather than this directory.
