# Engineering Decision Records (EDRs)

This directory contains Engineering Decision Records (EDRs) for Project Meadowlark.

An EDR documents significant engineering decisions that influence the architecture, implementation, or operation of the project.

Each record should answer four questions:

1. What decision was made?
2. Why was it made?
3. What alternatives were considered?
4. What are the expected consequences?

Engineering decisions should be recorded when they are expected to have long-term impact on the project. Routine implementation details or temporary experiments generally do not require an EDR.

EDRs are numbered sequentially to preserve project history and should not be renumbered after publication.
